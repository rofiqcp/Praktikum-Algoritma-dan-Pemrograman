# Tugas Video — Pertemuan 06

Video individu 12–20 menit.

## Bagian wajib
- Tunjukkan My Blocks Scratch dan function Python yang setara.
- Jelaskan parameter, argument, function call, dan return value.
- Jalankan kalkulator modular.
- Jalankan sistem nilai modular.
- Jalankan menu modular.
- Tunjukkan satu tracing nilai variable pada function.
- Jalankan test yang tersedia.
- Tampilkan satu refactor kecil dan bandingkan hasil sebelum/sesudah.

## Struktur
1. Identitas dan tujuan.
2. Dekomposisi masalah menjadi function.
3. Scratch My Blocks.
4. Function Python dan parameter/return.
5. Demo program modular.
6. Pengujian per function.
7. Tracing dan perbaikan hasil yang tidak sesuai.
8. Kesimpulan.

## Rubrik
Konsep 20%, demo 25%, modularitas 15%, testing 15%, penelusuran hasil 15%, penyampaian 10%.
