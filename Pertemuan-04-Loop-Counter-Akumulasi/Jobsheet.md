# Jobsheet Pertemuan 04 — Loop, Counter, dan Akumulasi

## Environment
Scratch + Google Colab + Python.

## Percobaan Wajib
| No | Percobaan | Fokus |
|---:|---|---|
| 1 | Tabungan harian | `for`, accumulator, tracing |
| 2 | Bilangan genap | `range`, kondisi, boundary |
| 3 | Tebak angka | `while`, sentinel kondisi |
| 4 | Kasir sentinel | input berulang sampai `0` |
| 5 | Pola bintang | nested loop |

## Urutan Menjalankan
1. Rakit padanan Scratch pada `praktikum/scratch/README.md`.
2. Jalankan semua file di `praktikum/python/`.
3. Buka notebook Colab dan **Run all**.
4. Buat tracing table minimal untuk satu program `for` dan satu `while`.

## Test Wajib
- `hari=1`, `hari=3`, `hari=0`.
- Rentang genap yang mencakup boundary.
- Tebak salah beberapa kali lalu benar.
- Kasir langsung memasukkan sentinel `0`.
- Nested loop ukuran 1 dan ukuran >1.

## Analisis
1. Kapan `for` lebih tepat dari `while`?
2. Mengapa accumulator harus dibuat sebelum loop?
3. Apa yang menyebabkan infinite loop?
4. Jelaskan off-by-one pada `range`.

## Debugging
Sengaja buat satu infinite-loop/off-by-one pada salinan kode, dokumentasikan gejala → penyebab → perbaikan → retest.
