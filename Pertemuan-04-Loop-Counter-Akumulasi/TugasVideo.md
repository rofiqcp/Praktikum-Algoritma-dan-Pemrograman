# Tugas Video — Pertemuan 04: Loop, Counter, dan Akumulasi

## Ketentuan

| Item | Ketentuan |
|---|---|
| Jenis | Video laporan praktikum individu |
| Durasi | 15–25 menit |
| Environment | Scratch + Google Colab/Python |
| Bukti utama | Program benar-benar dijalankan dan tracing ditunjukkan |
| Total skor | 100 poin |

## Isi Wajib

Video harus menunjukkan:

1. perbedaan `for` dan `while`;
2. cara kerja `range()`;
3. counter dan accumulator;
4. tracing perubahan variable;
5. akumulasi harian;
6. bilangan genap dalam rentang;
7. lima nilai dan rata-rata **tanpa list**;
8. pengulangan sampai condition terpenuhi;
9. sentinel sebagai penanda berhenti;
10. nested loop pola bintang;
11. satu perbandingan Scratch ↔ Python;
12. satu debugging loop sampai retest.

## Struktur Video

### 1. Pembukaan — 1–2 menit
Jelaskan identitas, tujuan, dan pertanyaan dasar: kapan jumlah iterasi diketahui dan kapan berhenti berdasarkan condition.

### 2. Konsep — 3–4 menit
Jelaskan `for`, `while`, `range(start, stop, step)`, counter, accumulator, dan stop eksklusif.

### 3. Demo `for` dan Accumulator — 4–5 menit
Jalankan program akumulasi harian. Sebelum Run, tampilkan tracing minimal tiga iterasi. Jelaskan nilai sebelum dan sesudah setiap penambahan.

### 4. Demo Range dan Rata-rata — 3–4 menit
Tunjukkan program bilangan genap serta program lima nilai tanpa list. Jelaskan mengapa accumulator cukup untuk menghitung rata-rata pada sesi ini.

### 5. Demo `while` dan Sentinel — 3–4 menit
Tunjukkan satu program yang jumlah iterasinya belum diketahui dan satu program input berulang sampai sentinel. Jelaskan kondisi yang membuat loop berhenti.

### 6. Nested Loop — 2–3 menit
Tampilkan pola bintang dan jelaskan outer loop versus inner loop menggunakan tracing per baris.

### 7. Debugging — 2–3 menit
Pilih satu: loop tidak berhenti, off-by-one, atau accumulator di-reset di dalam loop. Tunjukkan gejala, expected, actual, hipotesis, perbaikan, dan retest.

### 8. Penutup — 1–2 menit
Simpulkan cara memilih jenis loop dan mengapa tracing membantu menemukan error.
