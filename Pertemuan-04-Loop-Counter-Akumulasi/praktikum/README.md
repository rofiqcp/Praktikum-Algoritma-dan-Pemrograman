# Praktikum Pertemuan 04 — Loop, Counter, dan Akumulasi

Jalankan dari folder pertemuan secara berurutan:

```bash
python praktikum/python/01_tabungan_harian.py
python praktikum/python/02_bilangan_genap.py
python praktikum/python/06_rata_rata_lima_nilai.py
python praktikum/python/03_tebak_angka.py
python praktikum/python/04_kasir_sentinel.py
python praktikum/python/05_pola_bintang.py
```

Urutan ini mengikuti Jobsheet: akumulasi, `range()`, rata-rata tanpa list, `while`, sentinel, lalu nested loop.

Setelah program Python selesai:
1. buka `praktikum/colab/latihan_pertemuan04.ipynb` dan gunakan Run all;
2. gunakan `praktikum/colab/tabungan_harian.ipynb` sebagai contoh tambahan;
3. rakit padanan loop Scratch pada `praktikum/scratch/README.md`;
4. isi tracing table serta expected-versus-actual pada `Jobsheet.md`.

Untuk latihan debugging, ubah satu bagian pada salinan program, catat penyebabnya, perbaiki, lalu jalankan kembali test lama.
