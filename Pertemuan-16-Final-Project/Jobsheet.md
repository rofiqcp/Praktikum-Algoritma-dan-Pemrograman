# Jobsheet Pertemuan 16

1. Pilih satu project dari `Project.md`.
2. Tulis scope, user flow, ERD, API contract dan acceptance criteria.
3. Bangun backend + database lebih dulu dan test endpoint.
4. Integrasikan frontend Node setelah contract API stabil.
5. Implementasi loading/empty/error/success state.
6. Uji minimal 12 kasus end-to-end termasuk invalid, not-found, conflict, dependency/runtime failure.
7. Audit secret, parameterized SQL, validation dan error disclosure.
8. Siapkan README run/deploy, Git history dan demo end-to-end.

`praktikum/final-starter` hanya starter arsitektur, bukan jawaban final.
