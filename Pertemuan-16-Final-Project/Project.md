# Project Pertemuan 16 — Final Full Stack Node.js + Python + Database

## Ketentuan Umum
Node.js+Express web/frontend, Python Flask/FastAPI REST API/business logic, database relasional min 2 tabel + one-to-many, CRUD, validation/error handling, 12+ test case, ERD/API docs/Git/demo.

## 30 Pilihan
1. **Sistem Inventori dan Kategori** — categories→products, CRUD, pencarian, low stock.
2. **Perpustakaan dan Peminjaman** — books→loans, availability, pinjam/kembali, cegah double loan.
3. **Manajemen Kursus dan Peserta** — courses→enrollments, daftar/batal, kapasitas.
4. **Reservasi Meja Restoran** — tables→reservations, booking/batal/cari, cegah double booking.
5. **Sistem Laundry dan Item Pesanan** — orders→order_items, total backend, status proses.
6. **Bengkel Servis dan Riwayat Kendaraan** — vehicles→service_records, status dan history.
7. **Klinik Antrian Non-Medis** — patients→queue_entries, nomor/panggil/status tanpa diagnosis.
8. **Event dan Registrasi Peserta** — events→registrations, kapasitas dan duplikat.
9. **Rental Sepeda dan Transaksi** — bicycles→rentals, availability, tutup sewa, biaya.
10. **Hotel Mini dan Booking** — rooms→bookings, tanggal, cancel, overlap validation.
11. **Toko Buku dan Pesanan** — books/categories/orders, stock dan order history.
12. **Kafe: Menu dan Pesanan** — menu_items→order_items/orders, total dan status.
13. **Laboratorium: Alat dan Peminjaman** — equipments→borrowings, stok/history/low stock.
14. **Sekolah: Kelas dan Tugas** — classes→assignments, deadline/filter/relasi.
15. **Helpdesk Ticketing** — tickets→comments, status/prioritas/search/history.
16. **Manajemen Gudang dan Mutasi Stok** — products→stock_movements, stok dihitung dari mutasi.
17. **Sistem Donasi Barang** — donors→donations/items, status distribusi dan report.
18. **Agenda Organisasi dan Kehadiran** — events→attendances, persentase/filter.
19. **Pet Shop: Hewan dan Perawatan** — pets→care_records, administrasi non-medis dan history.
20. **Koperasi Mini: Produk dan Transaksi** — products→transaction_items, total/stok/report.
21. **Jadwal Ruangan dan Booking** — rooms→bookings, slot/cancel/no overlap.
22. **Asset IT dan Penugasan** — assets→assignments, assign/return/history.
23. **Sistem Paket dan Tracking Status** — packages→tracking_events, lookup dan timeline.
24. **Manajemen Proyek dan Task** — projects→tasks, status/prioritas/filter/progress.
25. **Penyewaan Peralatan Acara** — equipments→rental_items, availability/return/total.
26. **Katalog Wisata dan Itinerary** — destinations→itinerary_items, urutan/tanggal.
27. **Sistem Pesanan Catering** — menus→orders, porsi/tanggal/total/minimum order/status.
28. **Manajemen Kebun dan Catatan Panen** — plots/crops→harvest_records, agregasi periode.
29. **Sistem Klub dan Keanggotaan** — clubs→memberships, status/jumlah anggota.
30. **Pusat Pelatihan: Kelas dan Sertifikat Simulasi** — classes→participants/completions dan tampilan sertifikat simulasi.

## Deliverable
Source runnable, README masalah/arsitektur/fitur/install/run, ERD, API docs, tabel test, Git history, catatan error-solusi, demo final dan deployment bila platform memungkinkan.
