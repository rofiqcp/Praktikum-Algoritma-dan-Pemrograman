# Materi Pertemuan 16 — Final Project Full Stack

Final mengintegrasikan Node.js untuk web/frontend layer, Python untuk REST API/business logic, dan database relasional minimal dua tabel. Fokus bukan ukuran aplikasi, tetapi arsitektur jelas, validation, CRUD, relasi data, error handling, testing, Git history, deployment/demo, dan kemampuan menjelaskan end-to-end.

## Minimum
- Node + Express frontend/web layer.
- Python Flask/FastAPI API.
- Database relasional min. 2 tabel + relasi one-to-many.
- CRUD resource utama, validasi dan error state.
- Minimal 12 test case end-to-end.
- ERD/schema, API docs, README, Git history dan demo.
