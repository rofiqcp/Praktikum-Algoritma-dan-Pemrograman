# Jobsheet Pertemuan 09

1. Buat venv dan install requirements.
2. Jalankan `python app.py`.
3. Uji `/`, `/products`, `/products/new`.
4. Submit produk valid, nama kosong, harga negatif, stok bukan integer.
5. Tambah satu field dan satu komponen feedback sendiri.
6. Buat sengaja route 404 dan template error lalu diagnosa dari terminal.
