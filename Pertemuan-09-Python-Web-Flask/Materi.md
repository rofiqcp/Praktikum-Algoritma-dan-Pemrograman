# Materi Pertemuan 09 — Python Web Programming dengan Flask

## Target
Menjelaskan client/server/request/response/route/template/static, membuat web Flask minimal 3 halaman, form GET/POST, validasi server-side, dan struktur project rapi.

```text
Browser → HTTP Request → Flask Route → Python Logic → Template/Response → Browser
```
Frontend berinteraksi dengan user; backend menjalankan logic/validasi/data. Kenali layout, input, selection, action, data display, navigation, feedback dan state normal/hover/focus/disabled/loading/error/success.

## UX minimum
Hierarchy jelas, label input jelas, validation dekat field, loading/error/success state, responsive dasar, dan akses keyboard/focus.

## Troubleshooting
404=route/URL; 500=baca traceback backend; TemplateNotFound=folder/nama template; CSS hilang=static path/cache; form kosong=`name` tidak cocok dengan `request.form`.
