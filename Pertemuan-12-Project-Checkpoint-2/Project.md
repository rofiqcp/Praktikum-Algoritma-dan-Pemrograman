# Project Pertemuan 12 — Python Web + API + Deployment

## Ketentuan
Flask web utama, minimal 3 halaman/6 komponen UI, REST API internal, satu external/mock API dengan timeout/error handling, deploy public URL, env variable, minimal 10 test case termasuk API failure.

## 30 Pilihan
1. Dashboard Cuaca Kegiatan — kota, API cuaca/mock, state sukses/gagal, rencana kegiatan internal.
2. Konverter Mata Uang Perjalanan — nominal/kurs API/mock dan riwayat konversi.
3. Pencari Buku dan Reading List — katalog API/mock + reading list CRUD.
4. Papan Info Film — search film API/mock + watchlist + loading/error/no-result.
5. Dashboard Negara — data negara API/mock + favorit.
6. Perencana Menu dan Resep — search resep API/mock + rencana masak.
7. Pencari Fakta Angkasa — data space API/mock + catatan observasi.
8. Dashboard Gempa Edukasi — data gempa API/mock + filter + daftar belajar; bukan klaim real-time keselamatan.
9. Daftar Tugas + Quote API — todo CRUD; quote dependency boleh gagal tanpa merusak todo.
10. Katalog Produk Simulasi — mock product API + filter + wishlist.
11. Dashboard Harga Crypto Edukasi — data latihan + watchlist, tanpa rekomendasi investasi.
12. Pencari Universitas — search negara/kata kunci + shortlist.
13. Generator Profil Karakter — random user/character API/mock + favorit.
14. Dashboard Kualitas Udara Demo — data API/mock + sumber/timestamp + lokasi favorit; bukan nasihat medis.
15. Agenda Event Lokal Simulasi — mock events + filter + pilihan.
16. Pencari Museum/Koleksi — museum API/dataset mock + koleksi favorit.
17. Dashboard Hari Libur — negara/tahun + daftar hari libur + rencana.
18. Kamus Mini Online — dictionary API/mock + kosakata belajar.
19. Pencari Lokasi Kode Pos — lookup area + favorit + not-found state.
20. Dashboard GitHub Repository Publik — public GitHub API data + favorit; tanpa token pribadi untuk tugas dasar.
21. Papan Berita Teknologi Mock — feed pengajar/mock + card + bookmark.
22. Pencari Nama dan Statistik — query API/mock + pencarian favorit.
23. Dashboard Transportasi Mock — jadwal/rute simulasi + perjalanan pilihan.
24. Pencari Game Publik — game API/mock + wishlist.
25. Dashboard Open Data Kota — dataset pengajar/mock + filter + preset.
26. Pencari Foto Edukasi — API legal/mock metadata + favorit; key via env jika ada.
27. Catatan Belajar + Trivia — notes CRUD + trivia API; notes tetap jalan saat trivia gagal.
28. Dashboard Kursus Online Mock — kursus mock + filter + target belajar.
29. Planner Workout Edukasi — dataset latihan mock + rencana pribadi; fokus programming.
30. Dashboard Statistik Olahraga Mock — dataset skor/statistik mock + watchlist; hindari data live saat penilaian.

Deliverable: repo, README, endpoint docs, public URL, deployment evidence, tabel minimal 10 test case dan catatan troubleshooting.
