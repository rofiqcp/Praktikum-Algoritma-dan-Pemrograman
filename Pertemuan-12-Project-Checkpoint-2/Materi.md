# Materi Pertemuan 12 — Project Checkpoint 2

Checkpoint mengintegrasikan Python web Flask, HTML/CSS/JS dasar, REST API, integrasi external/mock API, error handling, GitHub dan deployment.

Minimum: Flask backend; minimal 3 halaman dan 6 komponen UI; REST API internal dengan JSON/status code; satu external/mock API dengan timeout/error state; deploy public URL; env variable untuk secret; minimal 10 test case termasuk API failure.
