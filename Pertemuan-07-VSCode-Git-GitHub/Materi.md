# Materi Pertemuan 07 — VS Code, Python Lokal, Git, dan GitHub

## Target
Membedakan editor/interpreter/terminal, menjalankan `.py`, membuat venv, memakai `pip`, serta Git `init/add/commit/push/pull/clone`.

Struktur minimum:
```text
belajar-python/
├── main.py
├── utils.py
├── README.md
├── requirements.txt
└── .gitignore
```

Virtual environment: `python -m venv .venv`; aktifkan lalu gunakan `python -m pip`. Git history harus berisi commit kecil bermakna. Jangan pernah commit `.env`/secret.
