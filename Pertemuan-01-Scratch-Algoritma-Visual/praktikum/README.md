# Praktikum Pertemuan 01 — Scratch

Pertemuan 1 **hanya menggunakan Scratch**. File `.md` di folder ini adalah spesifikasi blok yang harus dirakit di `https://scratch.mit.edu/` dan benar-benar dijalankan.

## Urutan Wajib

1. `01_sequence_event.md`
2. `02_variable_input.md`
3. `03_game_tangkap_koin.md`
4. `04_debug_challenge.md`

Simpan project Scratch Anda sendiri dengan nama seperti `P01_NIM_Nama.sb3` jika pengajar meminta file project.

## Cara Membuktikan Program Berjalan

Untuk setiap latihan: Green Flag → lakukan input/aksi → amati Stage/variable → screenshot → catat expected vs actual.

## Aturan Debug

Gunakan `say`, monitor variable, dan perubahan costume/position sebagai indikator. Ubah **satu** blok per eksperimen agar penyebab bug dapat ditelusuri.
