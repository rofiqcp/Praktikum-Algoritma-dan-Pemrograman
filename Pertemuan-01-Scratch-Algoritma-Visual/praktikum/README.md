# Praktikum Pertemuan 01 — Scratch

Pertemuan 1 **hanya menggunakan Scratch**. File `.md` di folder ini adalah spesifikasi blok yang harus dirakit di `https://scratch.mit.edu/` dan benar-benar dijalankan.

## Urutan Wajib

1. `01_sequence_event.md` — sequence dan event.
2. `02_variable_input.md` — variable, input, dan reset state.
3. `03_condition_loop.md` — condition, loop, dan sensing.
4. `04_game_tangkap_koin.md` — integrasi menjadi mini game lengkap.
5. `05_debug_challenge.md` — reproduce, diagnosis, perbaikan, dan retest.

File latihan lain di folder ini dapat digunakan sebagai pengayaan, tetapi urutan lima file di atas adalah jalur utama praktikum.

Simpan project Scratch Anda sendiri dengan nama seperti `P01_NIM_Nama.sb3` jika pengajar meminta file project.

## Cara Membuktikan Program Berjalan

Untuk setiap latihan: Green Flag → lakukan input/aksi → amati Stage/variable → screenshot → catat expected vs actual.

## Aturan Debug

Gunakan `say`, monitor variable, dan perubahan costume/position sebagai indikator. Ubah **satu** blok per eksperimen agar penyebab bug dapat ditelusuri. Setelah memperbaiki bug, ulangi test yang sebelumnya sudah lulus untuk memastikan tidak muncul regression.
