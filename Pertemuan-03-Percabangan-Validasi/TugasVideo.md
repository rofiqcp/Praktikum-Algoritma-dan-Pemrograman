# Tugas Video — Pertemuan 03: Percabangan, Operator Logika, dan Validasi

## Ketentuan

| Item | Ketentuan |
|---|---|
| Jenis | Video laporan praktikum individu |
| Durasi | 15–25 menit |
| Environment | Scratch + Google Colab/Python |
| Bukti utama | Program benar-benar dijalankan |
| Total skor | 100 poin |

## Isi Wajib

Mahasiswa harus menjelaskan dan mendemonstrasikan:

1. `if`, `if-else`, `if-elif-else`;
2. operator perbandingan dan `and`, `or`, `not`;
3. perbedaan validasi input dan rule keputusan;
4. boundary testing;
5. program sistem nilai;
6. tarif parkir;
7. seleksi dua syarat;
8. promo toko;
9. klasifikasi suhu;
10. satu versi Scratch yang setara;
11. minimal satu debugging condition sampai retest.

## Struktur Video

### Pembukaan — 1–2 menit
Jelaskan identitas, tujuan, dan konsep keputusan berdasarkan condition.

### Konsep — 3–5 menit
Gunakan contoh singkat untuk menunjukkan perbedaan `=`, `==`, `>`, `>=`, `and`, dan `or`. Jelaskan mengapa urutan `elif` penting.

### Demo Sistem Nilai — 4–5 menit
Jalankan minimal input `74`, `75`, `76`, `89`, `90`, `-1`, dan `101`. Sebut expected sebelum Run, lalu bandingkan actual.

### Demo Program Lain — 5–7 menit
Tunjukkan tarif parkir, seleksi dua syarat, promo, dan klasifikasi suhu. Untuk setiap program tunjukkan minimal satu normal case dan satu boundary.

### Scratch ↔ Python — 2–3 menit
Tunjukkan satu keputusan yang sama dalam Scratch dan Python. Jelaskan bahwa bentuk syntax berbeda, tetapi rule keputusan tetap sama.

### Debugging — 2–3 menit
Gunakan salah satu eksperimen: `>=` menjadi `>`, urutan condition ditukar, `and` menjadi `or`, atau indentasi berubah. Tunjukkan expected, actual, tracing condition, perbaikan, dan retest.

### Penutup — 1–2 menit
Simpulkan cara menulis rule sebelum membuat condition dan pentingnya boundary test.
