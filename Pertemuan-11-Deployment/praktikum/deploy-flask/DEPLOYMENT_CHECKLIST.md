# Deployment Checklist

- [ ] Clone bersih dapat di-install dan dijalankan.
- [ ] `requirements.txt` benar.
- [ ] Entry point/start command benar.
- [ ] `.env` tidak tracked.
- [ ] Environment variables dibuat di platform.
- [ ] Build sukses.
- [ ] Runtime service aktif.
- [ ] `/health` 200.
- [ ] Public URL diuji dari perangkat lain.
- [ ] Error log/failure drill didokumentasikan.
- [ ] README memuat langkah deploy dan troubleshooting.
