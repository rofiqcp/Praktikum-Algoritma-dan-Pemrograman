# Praktikum Pertemuan 11

Starter deployment ada di `deploy-flask/`. Jalankan lokal dan test sebelum deploy.

```bash
cd deploy-flask
python -m pip install -r requirements.txt
python app.py
python -m unittest -v test_app.py
```

**Catatan:** command deployment aktual mengikuti dokumentasi platform yang digunakan pada saat praktikum.
