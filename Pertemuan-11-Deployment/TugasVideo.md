# Tugas Video — Pertemuan 11

## Wajib Didemokan
- App berjalan lokal dan test lulus.
- GitHub repository dan file deployment penting.
- Environment variable tanpa membocorkan nilai secret.
- Proses deploy pada satu platform.
- Build log dan runtime log.
- Public URL dibuka dari browser/perangkat lain.
- `/health` sukses.
- Satu failure drill dan perbaikannya.

Jangan tampilkan token, credential, cookie sensitif, atau isi `.env`. Durasi rekomendasi 12–20 menit.
