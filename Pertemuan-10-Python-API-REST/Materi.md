# Materi Pertemuan 10 — Python API: HTTP, JSON, REST dan Integrasi

## Target
Anatomy request/response; GET/POST/PUT-PATCH/DELETE; JSON; REST; variasi SOAP/GraphQL/RPC-gRPC/WebSocket/SSE/Webhook; auth concept; testing browser/curl/Postman/requests.

Kenali method, URL/path, query parameter, headers, body. Status penting: 200,201,204,400,401,403,404,409,422,429,500,502/503.

CRUD: GET list/detail, POST create, PATCH partial update, DELETE. API key/token tidak boleh di-hard-code. CORS terutama kebijakan browser lintas origin; curl/Python client tidak sama dengan browser.

Troubleshooting: connection refused=server/port; 404=path;405=method;401/403=credential/permission;400/422=payload;500=backend log; timeout=network/dependency.
