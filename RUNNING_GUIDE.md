# Panduan Menjalankan Seluruh Praktikum

| Pertemuan | Environment | Program yang dijalankan |
|---|---|---|
| 1 | Scratch Web | `praktikum/README.md` — rakit blok dan jalankan green flag |
| 2–6 | Scratch + Google Colab + Python | `praktikum/scratch/`, notebook `.ipynb`, dan file `.py` |
| 7 | VS Code + Python lokal + Git | `praktikum/python-local/main.py` dan `test_utils.py` |
| 8 | Python CLI | `praktikum/starter-cli/main.py` sebagai starter checkpoint |
| 9 | Flask | `praktikum/flask-web/app.py` |
| 10 | Flask REST + requests | `praktikum/rest-api/app.py`, `client.py`, `test_api.py` |
| 11 | Flask deployment starter | `praktikum/deploy-flask/app.py` + `Procfile` |
| 12 | Flask web/API checkpoint | `praktikum/starter-web-api/app.py` |
| 13 | Node.js + Express | `praktikum/node-express/server.js` |
| 14 | Node + Python + SQLite | jalankan backend Python dan frontend Node |
| 15 | Structured full stack | backend Python berlayer + frontend Node |
| 16 | Final starter | Node frontend + Python API + SQLite dua tabel |

## Prinsip

- Jalankan contoh minimal sebelum mengerjakan challenge.
- Jangan commit `.env`, token, password, `node_modules`, `.venv`, atau file database hasil runtime.
- Untuk pertemuan 8, 12, dan 16, contoh runnable adalah **starter**, bukan jawaban dari 30 opsi project.
- Perintah rinci ada di `README.md` dalam folder praktikum masing-masing.
