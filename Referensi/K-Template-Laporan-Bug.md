# Lampiran K — Template Laporan Bug

| Field | Isi |
|---|---|
| Judul | Ringkas dan spesifik. |
| Environment | OS, version, browser, Python/Node, framework. |
| Precondition | State sebelum bug. |
| Steps | Langkah 1,2,3... |
| Expected | Yang seharusnya terjadi. |
| Actual | Yang benar-benar terjadi. |
| Evidence | Screenshot/log/request-response. |
| Frequency | Selalu/kadang. |
| Suspected layer | UI/network/API/database/deploy. |
| Fix | Perubahan yang dilakukan. |
| Regression test | Tes agar bug tidak kembali. |
