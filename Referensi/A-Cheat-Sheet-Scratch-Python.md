# Lampiran A — Cheat Sheet Scratch ↔ Python

| Konsep | Scratch | Python |
|---|---|---|
| Output | `say` | `print()` |
| Input | `ask and wait` / `answer` | `input()` |
| Variable | set/change variable | `x = ...`, `x += ...` |
| Condition | if / if else | `if / elif / else` |
| Loop terhitung | `repeat N` | `for ... in range(N)` |
| Loop kondisi | `repeat until` | `while ...` |
| List tambah | add item to list | `list.append(item)` |
| List hapus | delete item | `del` / `remove()` |
| Panjang list | length of list | `len(list)` |
| Function | My Blocks | `def nama(...):` |
| Random | pick random | `random.randint` / `choice` |
| Boolean | and/or/not | `and/or/not` |
