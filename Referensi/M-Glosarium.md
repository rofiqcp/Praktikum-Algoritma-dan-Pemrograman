# Lampiran M — Glosarium

| Istilah | Definisi ringkas |
|---|---|
| Algorithm | Urutan langkah untuk menyelesaikan masalah. |
| API | Antarmuka komunikasi antarperangkat lunak. |
| Backend | Bagian server yang menjalankan logic/data. |
| Branching | Percabangan keputusan. |
| Client | Pihak yang mengirim request ke server. |
| Commit | Checkpoint perubahan dalam Git. |
| CORS | Kebijakan browser untuk akses lintas origin. |
| CRUD | Create, Read, Update, Delete. |
| Database | Sistem penyimpanan data terstruktur. |
| Deploy | Menempatkan aplikasi agar berjalan pada environment target. |
| Endpoint | Alamat operasi tertentu pada API. |
| Environment variable | Konfigurasi yang diberikan melalui environment, tidak harus di-hard-code. |
| Frontend | Bagian aplikasi yang berinteraksi dengan user. |
| Function | Blok kode bernama yang dapat dipanggil. |
| Git | Version control system. |
| GitHub | Platform hosting repository Git dan kolaborasi. |
| HTTP | Protokol request-response web. |
| JSON | Format teks pertukaran data. |
| Loop | Pengulangan instruksi. |
| Middleware | Fungsi di jalur request-response. |
| Node.js | Runtime JavaScript di luar browser. |
| ORM | Pemetaan objek program ke tabel database. |
| Route | Aturan yang memetakan URL/method ke handler. |
| Server | Program/mesin yang melayani request. |
| SQL | Bahasa query relational database. |
| State | Keadaan data/program pada suatu waktu. |
| Template | File tampilan yang dapat diisi data dinamis. |
| Validation | Pemeriksaan apakah input memenuhi aturan. |
| Virtual environment | Lingkungan dependency Python terisolasi. |
| Webhook | Callback HTTP yang dipicu event dari sistem lain. |
