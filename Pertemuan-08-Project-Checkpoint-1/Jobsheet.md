# Jobsheet Pertemuan 08

1. Pilih satu dari 30 project pada `Project.md`.
2. Tulis requirement dan flowchart/pseudocode sebelum coding.
3. Pecah menjadi minimal 5 function.
4. Implementasikan menu minimal 4 operasi dan validasi.
5. Commit Git per fitur, bukan satu commit di akhir.
6. Uji minimal 8 kasus dan catat expected/actual.
7. Pastikan orang lain dapat menjalankan dari README.

Folder `praktikum/starter-cli/` adalah contoh struktur runnable, bukan jawaban project.
