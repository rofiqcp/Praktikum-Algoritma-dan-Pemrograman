# Praktikum Pertemuan 08 — Checkpoint 1

Pertemuan ini menggunakan satu project pilihan dari `../Project.md`. Starter `starter-cli/` digunakan untuk mempelajari struktur menu, function, data in-memory, dokumentasi flowchart, dan test case; starter bukan jawaban project.

## Workflow
1. Pilih project.
2. Tulis requirement.
3. Buat IPO dan struktur data.
4. Rancang minimal lima function.
5. Buat flowchart/pseudocode.
6. Implementasikan minimal empat operasi menu.
7. Lakukan minimal delapan test case.
8. Buat minimal lima commit progres.
9. Lengkapi README.
10. Siapkan demo 3–5 menit.

## Starter

```bash
cd starter-cli
python main.py
python -m unittest discover -s tests -v
```

Gunakan `../Jobsheet.md` sebagai lembar kerja lengkap dan `../Materi.md` untuk aturan checkpoint.
