# Praktikum Pertemuan 08 — Starter CLI

Starter ini menunjukkan **struktur**, bukan jawaban bank project.

```bash
cd starter-cli
python main.py
python -m unittest discover -s tests -v
```

Pelajari `app.py`, `FLOWCHART.md`, dan `TEST_CASES.md`, lalu buat repository project Anda sendiri dengan data/fitur sesuai pilihan pada `Project.md`.
