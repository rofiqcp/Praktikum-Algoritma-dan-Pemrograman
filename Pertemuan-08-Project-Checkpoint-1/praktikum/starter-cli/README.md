# Starter CLI — Pertemuan 08

Starter ini hanya contoh **struktur teknis** program CLI: data in-memory, menu, function, validasi dasar, dan test. Starter bukan jawaban untuk 30 pilihan project.

## Menjalankan

```bash
python main.py
```

## Menjalankan test

```bash
python -m unittest discover -s tests -v
```

## Yang Harus Dipelajari

1. Bagaimana `main.py` mengatur loop menu.
2. Bagaimana function kecil dipisahkan dari alur utama.
3. Bagaimana list/dictionary menyimpan state selama program berjalan.
4. Bagaimana input tidak valid ditangani.
5. Bagaimana function dapat diuji tanpa menjalankan seluruh menu.

## Cara Mengadaptasi ke Project Pilihan

Jangan mengganti nama project saja. Mulai dari requirement project Anda, kemudian tentukan:

```text
4+ operasi menu
5+ function bermakna
struktur list/dictionary
aturan validasi
8+ test case
5+ commit progres
```

Gunakan `FLOWCHART.md` dan `TEST_CASES.md` sebagai contoh format dokumentasi.
