# Project Pertemuan 08 — Algoritma + Python Lokal + GitHub

## Ketentuan Umum
CLI Python lokal, minimal 4 operasi menu, condition/loop/list-dictionary/function/validasi, minimal 5 function, 8 test case, dan 5 commit progres.

## 30 Pilihan Project
1. **Kasir Kantin Sekolah** — daftar menu, multi-item, subtotal/diskon, validasi menu/jumlah.
2. **Rekap Nilai Kelas** — nama/nilai, lulus, statistik, pencarian, validasi 0–100.
3. **Peminjaman Buku Kelas** — lihat/cari/pinjam/kembali dan status ketersediaan.
4. **Antrian Klinik Sekolah** — tambah, urutan, panggil, cari posisi, prioritas sederhana.
5. **Tabungan Mingguan** — setoran anggota, total/rata-rata/target/tertinggi, tolak negatif.
6. **Rental Alat Olahraga** — stok, pinjam/kembali, pencarian, stok tak boleh negatif.
7. **Voting Ketua Kelas** — kandidat, suara valid, perolehan, pemenang/seri.
8. **Perencana Anggaran Study Tour** — peserta, komponen biaya, total/per peserta/batas anggaran.
9. **Sistem Parkir Mini** — kendaraan masuk/keluar/cari/slot/tarif; cegah duplikat.
10. **Toko Buah** — nama/harga/stok, pembelian multi-item, total, tolak stok kurang.
11. **Jadwal Piket Kelas** — anggota per hari, cari/ganti, validasi nama.
12. **Skor Turnamen Mini** — hasil pertandingan, total poin, klasemen, seri.
13. **Laundry Kiloan** — layanan, berat, harga, layanan khusus, tolak berat <=0.
14. **Bengkel Servis Sederhana** — jasa/biaya, multi-servis, total/diskon, jasa valid.
15. **Pemesanan Tiket Acara** — kapasitas, pesan/batal/cari, cegah over-capacity.
16. **Pencatat Konsumsi Listrik** — data harian, total/rata-rata/hari tertinggi/ambang.
17. **Pengelola Stok Apotek Mini** — latihan data obat bebas: lihat/tambah/kurang/cari stok.
18. **Daftar Kehadiran Kegiatan** — hadir/tidak, persentase, pencarian, cegah duplikat.
19. **Perencana Menu Kafe** — menu/harga/stok, pesanan, total, item terlaris simulatif.
20. **Kalkulator Ongkir Paket** — berat/zona, biaya dasar/tambahan, ringkasan beberapa paket.
21. **Penyewaan Sepeda** — ketersediaan, sewa/kembali, durasi, biaya.
22. **Manajemen Kamar Penginapan Mini** — kamar/status, check-in/out, cari tamu, biaya malam.
23. **Kalkulator Gaji Harian** — jam kerja, normal/lembur, total dan rata-rata biaya tenaga kerja.
24. **Pemilihan Paket Internet** — filter paket berdasarkan kuota, anggaran, kebutuhan.
25. **Pencatat Hasil Panen** — hasil petak, total/rata-rata/max/min/target.
26. **Koleksi Film Pribadi** — judul/genre/status tonton, tambah/cari/tandai/filter.
27. **Peminjaman Alat Laboratorium** — stok, pinjam/kembali, low-stock warning.
28. **Reservasi Meja Restoran** — meja/kapasitas, reservasi/batal/cari sesuai jumlah tamu.
29. **Perencana Belanja Bulanan** — kebutuhan/biaya, total/sisa/item terbesar/over-budget.
30. **Jadwal Bus Sederhana** — rute/waktu/tarif, cari tujuan, pilih perjalanan, biaya penumpang.

## Deliverable
Source runnable, README, flowchart/pseudocode, tabel test case, Git history, catatan error/solusi, dan demo. Pilih satu project; rule detail boleh ditetapkan pengajar selama bobot inti setara.
