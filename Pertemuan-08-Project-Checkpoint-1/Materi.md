# Materi Pertemuan 08 — Project Checkpoint 1: Algoritma + Python Lokal + GitHub

> Sumber utama: *Buku Panduan Praktik: Pemrograman Dasar hingga Full Stack — 16 Pertemuan Terstruktur, Edisi Agustus 2026*.

Pertemuan 08 adalah **checkpoint**, bukan penambahan framework baru. Peserta memilih satu dari 30 soal cerita dan hanya memakai kompetensi pertemuan 1–7: algoritma, input-output, condition, loop, list/dictionary sederhana, function, validasi, VS Code, Git, dan GitHub. Web, API, Node.js, dan database belum diperlukan.

## Target Kompetensi
- Menerjemahkan soal cerita menjadi requirement dan algoritma.
- Membangun program CLI Python modular.
- Menggunakan Git secara bertahap selama pengerjaan.
- Menguji minimal 8 test case.
- Membuat README yang memungkinkan orang lain menjalankan program.

## Output Pertemuan
- Repository GitHub.
- Source Python berjalan lokal.
- README, flowchart/pseudocode, test-case table, dan demo 3–5 menit.

## Aturan Bobot Setara
- Menu utama minimal empat operasi.
- Wajib condition, loop, list/dictionary, function, dan validasi input.
- Data boleh hanya in-memory; file persistence adalah bonus.
- Minimal lima function bermakna.
- Minimal delapan test case: normal, boundary, invalid, dan not-found/capacity bila relevan.
- Minimal lima commit Git yang menunjukkan progres nyata.

## Rubrik
| Aspek | Bobot |
|---|---:|
| Analisis soal & flowchart | 15% |
| Fitur berjalan | 30% |
| Struktur function/data | 15% |
| Validasi & error handling | 15% |
| Testing | 10% |
| Git/GitHub & README | 10% |
| Demo & penjelasan | 5% |

## Workflow Project
```text
SOAL CERITA → REQUIREMENT → DATA MODEL → FLOWCHART → FUNCTION PLAN
→ IMPLEMENTASI KECIL → TEST → COMMIT → INTEGRASI → REGRESSION TEST
→ README → DEMO
```

Bank 30 project lengkap ada di `Project.md`. Starter pada `praktikum/starter-cli/` hanya contoh struktur teknis dan **bukan jawaban** dari bank project.
