# Materi Pertemuan 08 — Project Checkpoint 1

Checkpoint ini mengintegrasikan kompetensi pertemuan 1–7: algoritma, input/output, condition, loop, list/dictionary, function, validasi, Python lokal, VS Code, Git, dan GitHub. Tidak menggunakan web/API/Node/database.

## Minimum
- Menu terminal minimal 4 operasi.
- Minimal 5 function bermakna.
- Validasi input dan error message yang jelas.
- Minimal 8 test case: normal, boundary, invalid, data tidak ditemukan.
- Minimal 5 commit progres.
- README, flowchart/pseudocode, dan demo.
