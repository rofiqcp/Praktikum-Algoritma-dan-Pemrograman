# Tugas Video — Pertemuan 05

## Ketentuan
Video individu, durasi rekomendasi 12–20 menit. Program harus diperlihatkan benar-benar berjalan.

## Demo Wajib
1. List pada Scratch dan padanannya pada Python.
2. `01_statistik_nilai.py` untuk jumlah, minimum, maksimum, dan rata-rata.
3. `02_daftar_belanja.py` untuk tambah/tampil/cari.
4. `03_stok_barang.py` untuk dictionary dan key–value.
5. `04_suhu_harian.py`.
6. `05_voting.py`.
7. `06_pencarian_produk.py` dengan data tersedia dan tidak tersedia.
8. Satu challenge mandiri dan minimal tiga pengujian.

## Hal yang Harus Dijelaskan
- alasan memakai list;
- konsep index;
- loop pada list;
- pencarian data;
- statistik sederhana;
- perbedaan list dan dictionary;
- cara menangani kondisi data kosong atau data tidak ditemukan.
