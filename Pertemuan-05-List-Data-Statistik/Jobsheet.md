# Jobsheet Pertemuan 05 — List, Data, Pencarian, dan Statistik

## Tujuan
Mahasiswa mampu membuat dan memodifikasi list, melakukan loop dan pencarian, menghitung statistik sederhana, menggunakan dictionary, serta membandingkan implementasi Scratch dengan Python/Colab.

## Urutan Praktikum
1. Kerjakan latihan Scratch pada `praktikum/scratch/README.md`.
2. Jalankan notebook pada `praktikum/colab/` dari awal sampai akhir.
3. Jalankan seluruh program Python bernomor pada `praktikum/python/`.
4. Catat state data sebelum dan sesudah operasi.
5. Uji kasus normal, boundary, data kosong, dan data tidak ditemukan.
6. Kerjakan challenge mandiri.

## Percobaan Wajib

### P01 — Operasi List
Gunakan lima nilai awal. Lakukan akses elemen pertama/terakhir, update, append, remove/pop, dan pengukuran panjang list.

### P02 — Statistik Nilai
Jalankan `01_statistik_nilai.py`. Catat jumlah data, total, minimum, maksimum, dan rata-rata. Bandingkan dengan hitung manual.

### P03 — Daftar Belanja
Jalankan `02_daftar_belanja.py`. Uji tambah, tampil, pencarian data tersedia, dan pencarian data tidak tersedia.

### P04 — Dictionary/Stok
Jalankan `03_stok_barang.py`. Identifikasi key `nama`, `harga`, dan `stok`. Tambahkan satu record buatan sendiri.

### P05 — Suhu Harian
Jalankan `04_suhu_harian.py`. Uji beberapa nilai positif, nol, negatif, dan satu data saja.

### P06 — Voting
Jalankan `05_voting.py`. Identifikasi penggunaan list, loop, condition, dan counter. Uji kondisi hasil sama bila relevan.

### P07 — Pencarian Produk
Jalankan `06_pencarian_produk.py`. Uji huruf besar/kecil, spasi tambahan, produk tersedia, dan produk tidak tersedia.

## Pengujian Minimum
Siapkan minimal 10 test case. Setiap baris harus mempunyai fitur, input/state, expected, actual, dan status pass/fail. Pastikan terdapat kasus normal, satu data, boundary, data kosong, pencarian berhasil, dan pencarian tidak berhasil.

## Challenge
Pilih satu: jumlah nilai di atas rata-rata, penanda stok rendah, pencarian case-insensitive, fitur hapus data, atau menu mini tambah/tampil/cari/hapus/keluar. Tambahkan minimal tiga test case untuk challenge.

## Pertanyaan Analisis
1. Mengapa list lebih scalable daripada variable terpisah?
2. Mengapa index dimulai dari 0 penting?
3. Apa beda list dan dictionary?
4. Mengapa rata-rata membutuhkan pemeriksaan data kosong?
5. Bagaimana loop dan condition dari pertemuan sebelumnya digunakan kembali?
6. Kapan list of dictionaries lebih tepat digunakan?

## Bukti Pengumpulan
Project/screenshot Scratch, notebook Colab, output seluruh Python, tabel test, source challenge, jawaban analisis, dan kesimpulan.
