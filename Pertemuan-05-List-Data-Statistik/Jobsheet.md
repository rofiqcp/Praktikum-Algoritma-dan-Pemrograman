# Jobsheet Pertemuan 05 — List, Data, Pencarian, dan Statistik

## Environment
Scratch + Google Colab + Python.

## Percobaan Wajib
1. Statistik daftar nilai.
2. Daftar belanja interaktif.
3. Stok barang berbasis list of dictionaries.
4. Statistik suhu harian.
5. Voting sederhana.

## Cara Menjalankan
Rakit versi Scratch → jalankan semua `praktikum/python/*.py` → buka notebook Colab → Run all.

## Pengujian Wajib
- List normal dengan beberapa data.
- List satu elemen.
- List kosong (harus ditangani, tidak `ZeroDivisionError`).
- Pencarian data ditemukan/tidak ditemukan.
- Key dictionary benar/salah.
- Data duplikat pada voting/belanja.

## Analisis
1. Mengapa list lebih skalabel daripada banyak variable?
2. Apa beda index dan key?
3. Kapan `.get()` lebih aman daripada `[]` pada dictionary?
4. Mengapa statistik pada list kosong perlu validasi?

Tambah edit/delete/filter pada salah satu aplikasi dan buat regression test fitur lama.
