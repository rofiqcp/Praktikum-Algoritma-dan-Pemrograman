# Scratch P05 — List dan Statistik

Buat List `Nilai` serta variable `jumlahData`, `i`, `total`, `rata`, dan `lulus`.

## Praktik
1. Kosongkan List `Nilai` saat green flag diklik.
2. Minta jumlah data.
3. Ulangi input dan tambahkan setiap nilai ke List `Nilai`.
4. Loop seluruh isi list untuk menghitung total.
5. Hitung rata-rata jika list berisi data.
6. Tampilkan panjang list dan rata-rata.
7. Tambahkan challenge menghitung jumlah nilai minimal 75.
8. Tambahkan challenge pencarian satu nilai.

## Padanan Python
Scratch List setara dengan Python `list`; add item setara `append()`, length setara `len()`, dan repeat setara loop `for`.

Sebelum pindah ke Colab, mahasiswa harus dapat menjelaskan isi list setelah setiap input.
