# Jobsheet Pertemuan 13

1. Cek `node --version` dan `npm --version`.
2. Masuk `praktikum/node-express`, jalankan `npm install` lalu `npm start`.
3. Buka `http://localhost:3000` dan `/api/hello`.
4. Jelaskan `package.json`, `server.js`, `public/index.html`, `public/app.js`.
5. Tambah satu route JSON dan satu tombol frontend yang memanggilnya.
6. Simulasikan dependency hilang dan route 404; dokumentasikan bukti.
